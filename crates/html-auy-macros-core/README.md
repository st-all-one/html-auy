# html-auy-macros-core

Parser, validator, and code generator for the [`html-auy`](https://crates.io/crates/html-auy)
`html!` macro.

This is the implementation crate behind
[`html-auy-macros`](https://crates.io/crates/html-auy-macros). It is published because the
proc-macro crate depends on it; applications should use `html-auy` instead.
